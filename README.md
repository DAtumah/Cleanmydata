\# CleanMyData



Clean any CSV in seconds. Removes duplicates, trims spaces, lowercases emails, and flags missing values.



\## Web version

Open the live page, choose a CSV with a header row, fix problems in the table, preview the changes and download. Your file never leaves your computer.



\## Command line version

python cleaner.py your\_file.csv



Saves your\_file\_clean.csv next to the original and prints a summary.
